# نظيف TV — TV Clean Launcher

واجهة ويب عربية RTL للتلفزيون، بملفات منفصلة وخفيفة:
- `index.html` هي الصفحة الرئيسية.
- `styles.css` للتصميم والاستجابة لأحجام الشاشات.
- `app.js` للتنقل بالريموت، المفضلة، اللغة، الإعدادات، وحفظ التفضيلات محلياً.

## تشغيلها
افتح `index.html` في متصفح أو استخدم Live Preview في بيئة التطوير.

## ملاحظات مهمة
هذه نسخة واجهة ويب تجريبية. إضافة روابط لتطبيقات تفتح صفحات ويب فقط. فتح تطبيقات Android TV المثبتة مباشرة، قراءة التطبيقات المثبتة، والتحكم بخصائص النظام يتطلبان بناء Android أصلياً (مثل Kotlin/Java) وصلاحيات مناسبة. هذه الواجهة وحدها لا تنتج APK.

الإعدادات والمفضلة تُحفظ في `localStorage` على نفس المتصفح والجهاز.
